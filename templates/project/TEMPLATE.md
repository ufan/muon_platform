# Project template

Copy these files into a new repository (skill `muon-new-project`; developer guide §7):

- rename `gitignore` → `.gitignore` (it is kept unhidden here so that the template itself is not affected);
- replace every `<placeholder>`, including those in `.muon/repo.yml` and `openspec/config.yaml`;
- run `openspec init --tools <your AI tools>` in the new repository; it keeps the copied `openspec/config.yaml`;
- delete this file;
- add the repository to `platform/repos/workspace.repos`.
